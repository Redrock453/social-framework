# Перевірка тверджень

Для кожного спірного або абсурдного твердження:

1. **Хто перший сказав і де.** Знайди найранніший допис чи публікацію.
2. **Зерно.** Що з цього справді є в документах: заява органу, рішення суду, запис, декларація.
3. **Перекручення.** Що додано або змінено: «може бути» стало «є», чужі слова подано як факт, змінено посаду чи суму.
4. **Вердикт і рівень.** Вердикт: правда / ймовірно правда / частково / перекручено / не підтверджено / припущення / неправда / фейк. Рівень: A, B, C чи D.
5. **Як поширювалось.** Які групи каналів, наскільки швидко, скільки переглядів.
6. **Роль кожної публікації.** Познач `role` для кожної публікації твердження:
   - `origin` — першоджерело: найраніша знайдена публікація первинної заяви (рівно одна);
   - `reprint` — передрук, пересилка або переказ того самого джерела без нового незалежного підтвердження;
   - `independent` — незалежне підтвердження з іншого джерела.

   `independent_count` не вводиться вручну: він рахується з ролей як `origin` + `independent`, `reprint` не рахується. Публікація, яка підтверджує лише частину твердження (або бере цифру з уже порахованого джерела), не отримує `independent` для цього твердження. Це `role` публікації, не плутати з `evidence.role` в analytical findings.

Запиши через `fact_check`, з посиланнями на джерела; публікації передавай у `publications` (`url` + `role`, можна `date`, `quote`, `channel`, `reason`). Звичайні люди в коментарях — не об'єкт перевірки. Перевіряємо твердження, а не особи.
